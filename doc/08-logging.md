# Журналирование

Всё, что попадает в `awLog()`, видно в консоли Appwrite на вкладке
выполнения функции.

```dart
awLog('Функция запущена');
awLog('Тело:', ctx.req.bodyJson);   // подпись, затем JSON с отступами
awLogError('Не удалось:', exception);
```

| Функция | Что делает |
| --- | --- |
| `awLog(Object? message, [Object? data])` | Запись в журнал. С одним аргументом пишет сообщение, с двумя — подпись и отдельно данные |
| `awLogError(Object? message, [Object? data])` | То же в поток ошибок |

Карты и списки печатаются как JSON с отступами, строки — как есть, `null`
превращается в пустую строку. Если объект не сериализуется, вызывается
его `toString()` — журналирование не должно ронять функцию.

## Компактный вывод

```dart
AppwriteLogger.prettyPrint = false;
```

Отступы удобны человеку и мешают машине: если журналы собираются и
разбираются, компактная запись экономит место и читается инструментами.

## Порядок важен

`AppwriteLogger` — одиночка, который поднимает `AppwriteContext.initialize()`.
До этого вызова `awLog()` **молча ничего не делает**: не падает, но и не
пишет. Поэтому первая строка функции — всегда создание контекста.

Создавать логгер вручную не нужно.
